# Novaframe website

Video-first marketing agency for local businesses in Andhra Pradesh and Telangana (Telugu, English, Tinglish).

- `site/index.html` is the self-contained homepage (single file). Fill the `CONFIG` object near the bottom with the WhatsApp number, Instagram handle and email.
- `design-canvas/project/` holds the design canvas source (Main.dc.html and canvas.json), the Telugu/Tinglish version.
- `research/` holds the benchmark reports and the notes behind them.

Open items: real contact details, founder photos, intro Reel footage, GST/registration details, and a native Telugu review of all Telugu and Tinglish copy.
